# Nappe — démonstration interactive

Application de démonstration : https://ValerionGG.github.io/nappe-demo/#demo

Ce dépôt ne contient que la version compilée destinée au public.
Les données sont fictives et locales à chaque onglet. Aucun paiement,
virement, contrôle d'identité ou envoi de message réel n'est effectué.
Ne pas saisir de documents personnels ni de coordonnées bancaires réelles.

Hébergement statique GitHub Pages. Les fichiers `_headers` Cloudflare ne sont
pas appliqués par GitHub Pages. Aucun backend ni authentification de production.

Cette édition comprend les six tutoriels, trente réponses FAQ, quatre ateliers
isolés, l’onboarding assisté et le financement mixte PSP/complément marchand.
Les droits validés restent distincts du disponible dans la simulation. Les
propositions visuelles non intégrées sont signalées comme telles.

La galerie publique contient les analyses et liens vers les auteurs, sans
réhéberger les visuels tiers sans licence. Les courriels, documents internes,
pièces jointes et sources de développement ne sont pas publiés.
